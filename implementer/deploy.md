# Деплой

Куда: **Vercel Hobby**. Статика HTML, $0, поддомен `imya-gorod.vercel.app`.

На каждое демо:
1. Отдельный репо `roman1pr/<slug>-demo`
2. В корне статика (`index.html`)
3. Подключить репо к Vercel — каждый push в `main` катит сайт

Не класть все демо в один Vercel-проект: так сломнее выкинуть одно и дать ссылку клиенту.

GitHub Pages тоже $0, но URL хуже. Cloudflare Pages — запасной. Для этого оффера Vercel достаточно.
