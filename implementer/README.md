# implementer

Движок демо. Код сайта сюда не класть — только правила. Каждое демо живёт в своём репо.

1. Взять `ready` из `searcher/leads.csv`
2. Снять бренд и тексты с живого сайта
3. Собрать ≥2 страниц HTML/CSS в их цвете, без выдумки
4. Отдельный репо `*-demo` + Vercel
5. Записать ссылку в `demos/`
