# site-factory

Оркестратор полуавтомата: находит компании со старым сайтом, собирает демо в их бренде, выкладывает на Vercel.

```
site-factory/          этот репо
  searcher/            база лидов и правила поиска
  implementer/         движок демо
  demos/               указатели на отдельные репо демо
```

Каждое демо — свой репозиторий (`kvalitet-demo`, следующие так же). В `demos/` только ссылка и статус, не код сайта.

Деплой: **Vercel Hobby**, один проект на демо. Push в `main` — живая ссылка. Статика HTML, $0.
